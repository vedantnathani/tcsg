# Founders Portrait Directory
Place the 4 founder portrait photographs in this directory with the following filenames:

1. `deeksha-agrawal.jpg` (or .png / .webp)
2. `parshva-tatiya.jpg` (or .png / .webp)
3. `founder-3.jpg` (or .png / .webp)
4. `founder-4.jpg` (or .png / .webp)

Recommended dimensions: Aspect ratio 4:5 (e.g., 800px × 1000px or 600px × 750px), high contrast portrait.
If an image is not present or while loading, the site automatically displays a stylish editorial monogram avatar.
